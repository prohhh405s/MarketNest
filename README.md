# MarketNest — Seller Accounts

This is the seller-account milestone for the MarketNest learning marketplace.

**Start here:** open `SETUP.md` and follow it from Part 1.

Files:
- `index.html` — storefront, seller registration/login, dashboard
- `styles.css`, `seller.css` — page styles
- `app.js` — storefront and Supabase auth/database logic
- `supabase-config.js` — add your Supabase Project URL and publishable/anon key
- `setup.sql` — create the products table and secure Row Level Security policies
- `SETUP.md` — beginner setup and test instructions

This remains a learning project. Cart/checkout are still simulated. Do not use real customer data or payments.
